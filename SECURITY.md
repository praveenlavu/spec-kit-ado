# Security Policy

## Supported versions

Security fixes are made on the latest 0.x release line only. Please upgrade
to the newest release before reporting.

## Reporting a vulnerability

Report privately through GitHub: open the repository
(`praveenlavu/spec-kit-ado`), choose **Security -> Report a vulnerability**,
and fill in the form. Please do not open a public issue or pull request for
a suspected vulnerability.

Please include:

- the affected version (`ado --version`) and how it was installed
- steps to reproduce, or a minimal proof of concept
- what you expected, what happened, and the impact you see
- any suggested fix

Never paste a Personal Access Token (PAT), secret, or real organization data
into an issue, pull request, or report. Use fictional names (for example
`contoso` and work item `1001`). If a token may have been exposed, revoke it
in Azure DevOps first.
